# Lab Report: Host Triage & Windows Command Line Interpreter (cmd.exe)

## 1. The Defensive Value of Command-Line Interfaces (CLI)
While Graphical User Interfaces (GUIs) provide intuitive navigation for standard operations, security operations and incident response workflows rely heavily on the **Command-Line Interface (CLI)** via `cmd.exe`.

### Operational and Forensics Advantages of CLI Triage:
*   **Minimal Resource Overhead:** CLIs execute without the graphics-intensive layout engine of a GUI. This low memory footprint ensures diagnostic scripts can execute reliably on constrained or heavily throttled cloud instances without causing system deadlocks.
*   **Repeatable Automation:** Complex host triage strings can be systematically chained into programmatic batch scripts (`.bat`) or macros, allowing immediate, identical triage collections across hundreds of endpoints simultaneously during an active breach.
*   **Remote Engineering Availability:** Operating over headless secure shell environments (such as **OpenSSH for Windows**) allows analysts to perform rapid diagnostic queries over slow, low-bandwidth network channels where a remote desktop connection (RDP) would fail.

## 2. Environment Verification & Environmental Constraints
Before executing forensic utilities or threat hunting scripts on a target host, an analyst must verify the context and execution scope of the terminal binary.

*   `set` — Enumerates all active local and system-wide environment variables.
    *   *SOC Triage Impact:* Analysts query this variable tree to audit the **`Path=`** statement. The system path dictates the absolute directory parameters (`C:\Windows\system32; C:\Windows; ...`) that the operating system searches sequentially to locate execution binaries. Verifying this ensures that system utilities are launching from trusted paths rather than tampered directory strings planted by an adversary.
*   `ver` — Outputs the explicit operating system kernel version string (e.g., `Microsoft Windows [Version 10.0.17763.1821]`).
*   `cls` — Flushes the interactive terminal display buffer to clear visual workspaces during manual verification loops.

## 3. Advanced Endpoint Asset Discovery (`systeminfo`)
*   `systeminfo` — Queries the underlying hardware abstraction layer and security subsystem to compile an exhaustive snapshot of the host computer configuration.
    *   *Forensic Visibility:* This utility unmasks critical system attributes including the explicit **OS Name** (e.g., *Windows Server 2019 Datacenter*), precise **OS Build Type**, baseline processor architectures, physical memory allocations, and current network domain boundaries.
*   **Piping Architecture Control (`| more`):** Long-form data streams generated by binaries can be routed through the sequential output processor utilizing the pipe operator (e.g., `driverquery | more`). This blocks terminal buffer overflow, allowing investigators to parse lines page-by-page using the space bar, or forcefully break the execution thread using `Ctrl + C`.

## 4. Live Network Triage & Interface Diagnostics
During a suspected network breach or lateral movement investigation, a defender executes localized networking commands to confirm adapter state alignments and verify external boundary paths.

### A. IP Configuration Verification
*   `ipconfig` — Enters the local network adapter stack to display essential interface properties, outputting the active **IPv4/IPv6 Addresses**, local **Subnet Masks**, and the default **Gateway Router** endpoint.
*   `ipconfig /all` — Expands network discovery to output low-level technical infrastructure layers. 
    *   *SOC Investigation Value:* This command dumps the physical hardware **MAC Address** (critical for identifying hardware spoofing or unauthorized network interface cards), flags whether **DHCP** is dynamically managing lease configurations, and identifies the authoritative **DNS Servers** resolving external internet queries for the host.

### B. Network Boundary Path Validation (`ping`)
*   `ping <target_name>` — Transmits standardized Internet Control Message Protocol (**ICMP**) Echo Request packets to a target destination and listens for a corresponding Echo Reply.
    *   *Triage Application:* Proves two-way connectivity over the network plane. Analysts leverage ping diagnostics to verify if an isolated host can successfully communicate with an external internet server or domain controller, capturing vital network health metrics like Round-Trip Time (RTT) latency values and packet drop margins.
## 5. Advanced Network Route Discovery & Domain Verification
When assessing suspicious data streams or investigating a potential external data exfiltration vector, a security analyst uses route tracking and name resolution diagnostics to map out transmission footprints:

*   `tracert <target_destination>` (Trace Route) — Maps out the hop-by-hop layer-3 route across routers to track the absolute path packets take to reach a destination.
    *   *SOC Investigation Triage:* Uses Time-to-Live (TTL) expiration drops to force intermediate routers to log their IP strings. Investigators leverage this diagnostic tool to find network anomalies, trace lateral movement paths, or pinpoint unauthorized proxy nodes diverting corporate outbound connections.
*   `nslookup <domain_name> [optional_dns_server]` — Queries local or external Domain Name System (DNS) servers to map a readable domain string (e.g., `example.com`) directly to its absolute public IP address allocation.
    *   *Threat Intelligence Pivot:* Analysts append an explicit external DNS infrastructure target (e.g., `nslookup malicious-domain.com 1.1.1.1`) to cross-reference resolution behaviors, verify DNS cache tampering attempts, or bypass local falsified hosts entries.

## 6. Live Socket Auditing & Network Connection Analysis (`netstat`)
Monitoring active connections and listener ports is a critical component of host forensic triage. Running the baseline `netstat` binary yields standard established streams, but incident responders combine flags to extract deep process mappings:

*   **`netstat -abon` Configuration String:**
    *   `-a` — Enumerates all active established connections and listening port sockets.
    *   `-b` — Dissects execution blocks to unmask the exact application executable name (e.g., `sshd.exe`, `svchost.exe`) binding to the network connection layer.
    *   `-o` — Appends the authoritative Kernel **Process ID (PID)** mapping for every running network stream.
    *   `-n` — Enforces absolute numerical notation for IP structures and socket ports, suppressing DNS resolution latency loops.
*   *Malware Triage Application:* Analysts run `netstat -abon` to detect malicious background connections, unmask rogue binaries masquerading as standard software, and isolate unauthorized listening sockets left behind as interactive access hooks by adversaries.

## 7. Volatile File System Traversal & Object Auditing
When exploring a compromised endpoint terminal shell to uncover hidden tool directories or audit file data integrity, analysts utilize the native file system manipulation engine:

### A. Directory Traversal & Structure Mapping
*   `cd` (With No Parameters) — Outputs the absolute drive mapping and directory path of the active interactive command-line session scope (the equivalent of asking the kernel, "Where am I?").
*   `cd <target_directory>` — Shifts the terminal shell focus directly into the target folder space. Append `cd ..` to shift the current directory layout up one level sequentially.
*   `dir` — Enumerates child subfolders, standard files, and structural metadata tags within the current workspace path. High-visibility diagnostic switches include:
    *   `dir /a` — Forces the terminal display to unmask hidden objects and high-privilege system files bypassed by default graphical interfaces.
    *   `dir /s` — Executes a recursive lookup string to detail all internal object folders and nested sub-elements contained in all lower branches.
*   `tree` — Generates an interactive visual folder schema illustration tracking all nested child folders and directory branches at a glance.

### B. Workspace Modification & Data Inspection
*   `mkdir <directory_name>` (Make Directory) — Instantiates a fresh standalone logical storage folder partition inside the active path.
*   `rmdir <directory_name>` (Remove Directory) — Deletes an empty target folder.
*   `type <file_name>` — Reads the binary structure of an asset file to output raw text directly into the command window buffer space.
    *   *SOC Triage Note:* Convenient for immediate inspection of small configuration scripts, batch files, or incident logs. For longer files that would trigger terminal buffer overflow, analysts pipe output metadata directly through the sequential display controller (`type access.log | more`) to page down safely.
## 8. High-Efficiency File Lifecycle Operations & Wildcard Mechanics
When handling volatile forensic drop-files, backing up local configuration profiles, or cleaning up data stages on a compromised target host, analysts use standard console utilities to manipulate object files directly:

*   `copy <source_file> <destination_path>` — Clones data contents from an existing source entity into a designated destination path or a new standalone file instance.
*   `move <source_file> <destination_path>` — Teleports a file path or dynamically renames system objects by altering or merging target path variables (e.g., shifting an item up one level using `move target.txt ..`).
*   `del <file_name>` (or `erase`) — Permanently purges file entries from the system partition.
*   **Wildcard Execution Control (`*`):** Security engineers utilize the asterisk character as an unconditional wildcard token to execute bulk automation tasks matching specific file formats or extensions (e.g., executing `copy *.md C:\Markdown` to isolate and duplicate all markdown files across paths instantly).

## 9. Host Process Supervision & Active Threat Termination
Identifying anomalous execution threads, hunting down memory persistent payloads, and killing rogue malicious processes are foundational incident response workflows managed natively via the command prompt:

*   `tasklist` — Queries the local execution subsystem to return a complete, static snapshot ledger detailing all running memory applications, active PIDs (Process IDs), session designations, and individual physical memory usage footprints.
*   **Targeted Telemetry Filtering (`/FI`):** Long-form process outputs can be systematically scoped down utilizing specific equality constraints wrapped in structural quote blocks to target suspicious parent processes instantly.
    *   *Forensic Query Syntax:*
        ```cmd
        tasklist /FI "imagename eq sshd.exe"
        ```
*   `taskkill /PID <target_pid>` — Forces termination of a specific process running in memory by forwarding a shutdown command directly to its Process ID mapping (e.g., `taskkill /PID 4567`).

## 10. Core Administrative Maintenance & Disk Triage Utilities
To round out comprehensive host auditing capabilities, defenders utilize three native high-privilege configuration maintenance tools:

*   `chkdsk` — Systematically audits active storage file systems, isolates bad sectors, and reviews storage partition volumes for low-level system damage.
*   `driverquery` — Compiles a comprehensive inventory tracking all installed physical device drivers and kernel-level modules currently loaded into the system architecture.
*   `sfc /scannow` (System File Checker) — Initiates an immediate integrity check over protected operating system paths, parsing infrastructure files for signs of corruption or administrative tampering, and automatically repairs broken assets using trusted system cached baseline repositories.
